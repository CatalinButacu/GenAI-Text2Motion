## Before moving anything
1. **`infra/aws/dissertation_v2.pem`** is a private key inside the repo. Rotate it and delete it from the repo.
2. **`infra/aws/terraform.tfstate`** lists an EC2 instance as running. Check the AWS console first, then delete the state file from the repo.
3. Check whether any hook calls the three scripts in `.claude/` before moving them.

## Steps (each followed by `make check`)

2. `artifacts/` → `runs/`, `dist/` → `build/`, update `configs/` and `Makefile`.
3. `doc/`, `.claude/docs`, `.claude/decisions`, `.claude/_archive`, `.archify/` → `docs/`. Update `CLAUDE.md`, `AGENTS.md`, hook paths.
4. `graphify-out/` → `.graph/`, `infra/` → `deploy/`, `licenses/` and `typings/` → `third_party/`, `Dockerfile` and `compose.yaml` → `deploy/`.
5. Scripts and `.claude` loose files into `scripts/`. `imgui.ini` into `.gitignore`.
